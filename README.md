## 📥 Download Instructions (Split Archive Method)

Because GitHub enforces a **strict 2 GB file size limit per individual asset** in Releases, the **PrismCore** ISO image has been split into multiple archive parts. 

To obtain the working ISO image, follow these simple steps:

### 1. Prerequisites
You need an extraction tool that supports split archives installed on your system, such as **7-Zip** (recommended) or WinRAR.

### 2. Download the Volumes
Go to the **Releases** section of this repository and download all six archive parts corresponding to the current version:
* `PrismCore_v1.0.7z.001`
* `PrismCore_v1.0.7z.002`
* `PrismCore_v1.0.7z.003`
* `PrismCore_v1.0.7z.004`
* `PrismCore_v1.0.7z.005`
* `PrismCore_v1.0.7z.006`

> **Important:** All files must be saved **in the same folder** on your computer for the merging process to work properly.

### 3. Extraction and Reconstruction
1. Right-click on the first part (`PrismCore_v1.0.7z.001`).
2. Select **7-Zip > Extract Here** (or use your equivalent software).
3. The program will automatically detect the remaining parts, seamlessly merge them, and extract the original intact ISO image.
